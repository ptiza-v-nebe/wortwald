# Wortwald — Лес слов (веб-версия, v3)

Что нового по сравнению с v2:
- проводник Искра (Funke) — последнее живое слово, ехидный огонёк, который летает рядом;
- Ома стала бойкой и язвительной, но по-прежнему добрая;
- девять отдельных мест вместо одной большой карты: площадь, дом Омы, поле, мастерская, причал, луг с пещерой, дремучий лес, волшебная поляна, башня;
- сплав на плоту: камни, брёвна и водовороты, а кнопки — немецкие слова;
- подсказки: над вещью с новым словом мерцают искорки, над тем, кто двигает сюжет, висит «!»;
- карточка со всеми словами главы в конце каждой главы;
- 6–8 новых слов на главу, слабые слова Искра спрашивает по дороге, а если отвечаешь быстро и правильно, объяснения становятся короче;
- неправильные ответы не наказывают, а смешат.

v1 и v2 сохранены отдельно и не изменялись.

## Как выложить на GitHub Pages
1. Создай на GitHub новый публичный репозиторий, например `wortwald`.
2. Загрузи в него файл `index.html` (Add file → Upload files).
3. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через минуту-две игра будет по адресу `https://<твой-логин>.github.io/wortwald/`.

## Как поменять игру
Исходники лежат в `src/` (каждый файл отвечает за свою часть), слова — в `words.py`.
После правок собери `index.html` заново командой `python3 build.py`. Готовый файл появится в `dist/index.html`.

## Управление
- Телефон: джойстик слева, кнопка **E** — говорить и трогать, «прыжок», «бег», книжка вверху — книга слов.
- Компьютер: стрелки/WASD, E, ПРОБЕЛ, SHIFT, TAB, R (повторить фразу), ESC.

Немецкие слова произносит встроенный синтезатор речи браузера (de-DE). На Android это голос Google.
Если немецкого голоса нет: Настройки → Язык и ввод → Синтез речи → установить немецкий.
Сохранение хранится в браузере на этом устройстве.

- Шуток меньше, остались только ситуационные (Белло ворует хлеб, овца за деревом, кляксы Лотте).

## v4.1
- Повторение по дороге («Что это?»): только то, что можно показать картинкой (вещи, животные, цвета). Слова каждый раз разные, ошибки и редкие слова всплывают чаще, последние 4 не повторяются. На повторных переходах между деревней, полем, мастерской и рекой иногда тоже спрашивает.
- Подсказки к немецким фразам: через 4 секунды (у сборки фраз через 6) появляется «H — подсказка» / «? подсказка». Нажми H или на неё, и увидишь перевод.

## v4.2 — режим разработчика
- На титульном экране справа внизу бледный жучок. Нажми на него, и откроется режим сцен.
- Сверху полоска: номер и название сцены (21 главная сцена), ◀ назад, ↻ заново, ▶ дальше, «авто», ✕ выход. Клавиши: N дальше, B назад, P авто.
- Всё до выбранной сцены проматывается мгновенно и беззвучно, а сама сцена играется вживую: герой сам ходит, трогает и разговаривает, ты только щёлкаешь диалоги. С «авто» диалоги и мини-игры листаются сами, и сцены идут подряд.
- В этом режиме ничего не сохраняется, обычное сохранение не трогается.

## v4.3
- Голос надёжнее: голоса ищутся заново, если браузер загрузил их поздно; «уснувший» синтезатор будится; фраза произносится чуть позже после сброса (иначе некоторые браузеры её глотают).
