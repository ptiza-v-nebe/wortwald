# Wortwald — Лес слов

Игра для русскоговорящих, которые начинают учить немецкий: слово появляется после ощущения, а не после объяснения.

- Играть: корень сайта (`index.html`) — текущая версия.
- Все версии: `versions/`.
- Исходники текущей версии: `source/` (`python3 build.py` собирает `dist/index.html`).
